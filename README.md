activities of **RomHack Camp 2026**, organized by
[Cyber Saiyan](https://www.cybersaiyan.it).

## Contents

This repository collects the material shared by speakers. Content is organized by topic/speaker, one folder each:

```

├── <talk-or-workshop-name>/

└── ...
```

## Contributing

1. Create a folder named after your talk or workshop (lowercase, hyphens).
2. Add a short `README.md` with title, speaker and a description.
3. Add your materials (slides in PDF, code, datasets, links).
4. Open a pull request.

Please do **not** upload malware samples, credentials, API keys or any
sensitive/personal data. If a workshop requires samples, share them in
password-protected archives and document the password in the folder README.

## Disclaimer

All material is provided for educational and research purposes only. Use it
responsibly and only on systems you own or are authorized to test.
