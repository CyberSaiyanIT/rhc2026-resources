# Codice Python Sicuro: Buone Pratiche e Strumenti di Analisi

- **Speaker(s):** Matteo Vitali (trotto)
- **Event:** RomHack Camp 2026 (2026-10-03, Talk)

## Abstract

Nel mondo attuale dello sviluppo software, la sicurezza non può più essere un ripensamento. Con l'approccio DevSecOps e il principio "shift left", gli sviluppatori svolgono un ruolo proattivo nell'integrare la sicurezza fin dalle prime fasi dello sviluppo, contribuendo a rendere le applicazioni più sicure e resilienti. In questo talk esploreremo best practices per scrivere codice sicuro e presenteremo alcuni strumenti che aiutano ad automatizzare la rilevazione di vulnerabilità nel nostro codice Python e nelle dipendenze.
