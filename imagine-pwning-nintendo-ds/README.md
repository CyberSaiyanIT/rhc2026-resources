# Imagine: pwning your favourite Nintendo DS game!

- **Speaker(s):** daisy
- **Event:** RomHack Camp 2026 (2026-10-04, Talk)

## Abstract

Imagine pwning a game from your childhood! 
What could possibly go wrong with a cute Nintendo DS game?

This talk will include a brief overview of the game, some useful details about Nintendo DS internals, the exploitation process, and a few other interesting observations I made while reversing it.
