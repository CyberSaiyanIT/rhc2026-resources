# When IaC goes wrong

- **Speaker(s):** Sean Juroviesky
- **Event:** RomHack Camp 2026 (2026-10-04, Talk)

## Abstract

The infrastructure team built out an automated and orchestrated solution to simplify it all, access, scaling ect. Alas the team who built it has left or is allocated to another project; services and infrastructure are breaking. This session will examine the challenges of lifecycle management that IaC can create, and uncover a few strategies you can use to prevent it.
