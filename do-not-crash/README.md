# "Don't crash" challenges walkthrough 

- **Speaker(s):** Max 'Sparrrgh' Bellia
- **Event:** RomHack Camp 2026 (2026-10-03, Workshop)

## Abstract

You've always wanted to start with binary exploitation challenges, but fear the horrors of weird machines? This will be a workshop for you! After a theoretical introduction on binary exploitation basics all the way to x86_64 Return Oriented Programming you will get your hands dirty with the "Don't crash" challenges with the help of the author. Bring your Linux laptop (or VM) with Ghidra, pwntools and pwndbg

Find the challenges at:
https://donotcrash.sparrrgh.me
